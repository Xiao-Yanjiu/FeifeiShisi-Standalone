# 参考与边界

防掉线参考研究： https://github.com/NightmareXIV/AntiAfkKick 。该项目同时包含独立版、卫月版和 ACT 版；独立版通过目标窗口的修饰键消息实现活动提示。本适配没有复制其代码，使用 Windows SendMessageTimeout 独立实现目标窗口消息，增加所选 PID、进程创建时间、窗口类名与角色一致性验证，不抢前台，不向其他窗口注入全局按键。

此组件已接入桌面宿主并通过时间、窗口与角色判定的自动检查；尚未进行长时间挂机效果实测。开关默认关闭，选中角色退出/切换时停止发送。游戏自身网络故障、维护或服务器强制断线不在其处理范围。
